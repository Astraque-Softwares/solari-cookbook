---
title: discover
description: Search one fault family for the smallest deterministic trigger, then confirm it.
---

```bash
flakelab discover <test> [options]
```

Runs matched-seed control and intervention trials, minimizes the fault boundary,
independently confirms the result, and writes a strict YAML reproducer plus a JSON discovery
sidecar.

## Core options

| Option | Default | Meaning |
| --- | --- | --- |
| `--fault <family>` | `network-delay` | Fault family to search. |
| `--pattern <glob>` | `**/api/checkout` | Request or document pattern for applicable faults. |
| `--trials <number>` | `4` | Trials per candidate batch. |
| `--concurrency <n>` | `2` | Playwright workers per trial batch. Use `1` for suites with unsafe shared state. |
| `--min-rate <rate>` | `0.7` | Requested intervention failure rate, greater than 0 and at most 1. |
| `--seed <number>` | `1` | Deterministic seed. |
| `--max-seconds <n>` | `600` | Elapsed-time ceiling for discovery. |
| `--output <path>` | `flakelab.repro.yaml` | Reproducer path. |

Fault-specific bounds are listed in the [fault catalog](/docs/faults).

## Progress output

Discovery prints one line per completed trial to stderr, carrying the running count, the
outcome, the trial duration, the pass/fail split, and how much of the time budget is spent.
Standard output stays reserved for the JSON result.

```text
› discovery · network-delay · bounded to 10m 0s · stable triggers receive a 12-trial confirmation
  · trial 1 · passed · 4.2s · 1 passed / 0 failed · 4.2s of 5m 0s
  · trial 2 · failed · 5.4s · 1 passed / 1 failed · 9.6s of 5m 0s
```

## Examples

```bash
flakelab discover tests/checkout.spec.ts \
  --fault network-delay \
  --pattern "**/api/checkout" \
  --max-delay 250

flakelab discover tests/payload.spec.ts \
  --fault response-truncation \
  --max-remove-bytes 64
```

<Callout type="warn">
If the control arm is itself noisy, discovery may end without a confident trigger. That is a
deliberate refusal to overclaim, not a bug - raise `--trials`, tighten the target, or pick a
fault family that matches the suspected mechanism.
</Callout>
