title: FlakeLab
description: Find, reproduce, explain, and prove fixes for flaky Playwright tests.
---

FlakeLab turns an intermittent Playwright failure into a controlled experiment. It searches
for a deterministic trigger, tests competing explanations against evidence, generates one
narrow source candidate, and proves that candidate in a disposable sandbox - then hands you
a reproducer, a proof matrix, and an offline report.

The principle behind every stage: **AI proposes; deterministic evidence decides.**

## Install nothing

```bash
npx flakelab@latest doctor
npx flakelab@latest diagnose tests/checkout.spec.ts
```

`doctor` and `diagnose` consume no provider credits. FlakeLab uses your existing Playwright
configuration; your tests keep importing `test` and `expect` from `@playwright/test`, and no
fixture or source edit is required.

## The shape of a run

```text
observe  ->  reproduce  ->  explain  ->  repair  ->  prove  ->  review
  |             |             |            |          |          |
 scan        discover     investigate    repair     Solari     report
 analyze     replay                                 microVM
  |             |             |            |          |          |
 free         free          Groq       Groq+Solari  Solari      free
```

`diagnose` is the recommended entry point. It starts with the cheapest useful operation and
moves into provider-backed work only when you explicitly ask for it.
